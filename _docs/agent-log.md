# Agent log

Raw notes for the README section "How I worked with agents". One line per event, newest last.

Format: `HH:MM | who (orchestrator / pm / engineer:lane / qa / me) | what happened | what I changed`

Log especially:
- parallel launches (which agents, which lanes)
- QA FAILs and how they were resolved
- times you corrected an agent, and the `process:` commit that fixed the cause
- times you overruled an agent and why
